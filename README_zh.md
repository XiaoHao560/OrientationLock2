## 简介

本项目是 [tuyafeng/OrientationLock](https://github.com/tuyafeng/OrientationLock) 的延续维护版本。由于原项目已长期处于停更状态，为了使其能够继续适配新版 Android 系统并持续提供稳定、轻量的方向锁定体验，我们决定在此基础上进行更新与维护。
